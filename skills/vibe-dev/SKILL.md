# Vibe Dev & Live Prototyping

Use this skill when building web applications, landing pages, interactive prototypes, or UI components where immediate visual feedback is essential.

## Principles
1. **Interactive First**: Build functional HTML/CSS/JS components rather than static descriptions.
2. **Instant Preview**: Produce single-file runnable prototypes or mount directly into dev preview servers.
3. **Micro-Iterations**: Make targeted UI updates with responsive design tokens and dark/light mode fidelity.
4. **Dynamic Island Integration**: Reflect build and prototype state directly into the HUD status bar.
